## 🔥 Project Overview

**This tool** is a comprehensive trainer for **MARVEL Tōkon: Fighting Souls**. This trainer provides offline practice and arcade-oriented options for managing the shared team health bar, Skill Gauge, opponent vitality, and round timer. It is intended for training, Episode Mode, local Versus, All-Star Arena, and other offline content.

**Target Audience:** Players practicing combos, team compositions, assists, Skill Gauge management, defensive techniques, stage transitions, and character matchups in offline modes.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

MARVEL Tōkon: Fighting Souls is a stage-based fighting game rather than an exploration game. Use the trainer while practicing movement, dashes, blocking, backsteps, character switches, and positioning around multi-sectioned stages.

### Tools & Inventory

The game has no traditional inventory system. Trainer options are applied directly to battle values such as team health, Skill Gauge, opponent health, and the round timer.

### World & Environment

The game features dynamic Marvel-themed fighting stages, some with interactive transitions. Trainer functions are intended for offline battles and do not modify the game’s story progression, online lobby, roster ownership, or downloadable content.

### Combat & Weapons

Build a four-character team and use Light, Medium, and Heavy attacks, Skills, Super Skills, Ultimate Skills, Assemble Assist attacks, character switching, Assemble Counter, Crossover, and Link Attack combos. Infinite Team Health supports extended testing, Infinite Skill Gauge enables repeated special attacks, Opponent Health Lock helps with combo demonstrations, and Round Timer Freeze allows uninterrupted practice.
